# Site React + Vite

Base minimale React + TypeScript + Vite, avec une page blanche.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

Commencez dans `src/App.tsx` et ajoutez vos styles dans `src/styles.css`.
`src/visual.css` contient les ajustements visuels effectués dans le Studio.

Le build autonome est généré dans `dist/`.
